# Contributing to BearClaw

Thanks for your interest in contributing to BearClaw.

## Development Setup

```bash
git clone https://github.com/ferrants/bearclaw.git
cd bearclaw
pnpm install
```

## Running Tests

```bash
pnpm -C packages/bearclaw test           # Run all tests
pnpm -C packages/bearclaw test:watch     # Run tests in watch mode
pnpm -C packages/bearclaw typecheck      # Type check
```

## Project Structure

- `packages/bearclaw/src/` — TypeScript source files
- `packages/bearclaw/tests/` — Test files (mirrors `src/` structure)
- `packages/bearclaw/dist/` — Compiled output (generated by `pnpm -C packages/bearclaw build`)
- `packages/bearclaw-tui/` — Terminal UI client (Bun runtime)

## Guidelines

- TypeScript strict mode is enforced
- All provider integrations use `fetch()` directly — no SDK dependencies
- Security is a core concern — consider implications of any changes to the security layer
- Keep runtime dependencies minimal

## Submitting Changes

1. Fork the repository
2. Create a branch for your change
3. Make your changes and add tests
4. Run `pnpm -C packages/bearclaw test` and `pnpm -C packages/bearclaw typecheck`
5. Open a pull request
